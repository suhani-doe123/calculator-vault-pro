# 🔐 Calculator Vault

A modern and secure Calculator Vault Android application that looks like a normal calculator while providing a private space for storing photos and videos.

## ✨ Features

- 🧮 Functional calculator
- 🔐 Hidden vault access
- 🔢 PIN protection
- 📷 Private photo storage
- 🎥 Private video storage
- ☁️ Firebase cloud storage
- 👤 Google Sign-In
- 🆓 Free plan with 1 GB storage
- ⭐ Premium plan with 10 GB storage
- 💳 Google Play subscription support
- 🔄 Automatic premium verification
- 📱 Android app powered by Capacitor

## 💾 Storage Plans

| Plan | Storage | Price |
|------|---------|-------|
| 🆓 Free | 1 GB | Free |
| ⭐ Premium | 10 GB | $15/month |

Premium storage is granted only after successful Google Play subscription verification.
